# ร้านระเบียงบัว ศรีสมาน — ระบบควบคุมจอโปรโมทในห้องคาราโอเกะ

WebApp สำหรับส่ง **รูปโปรโมชั่น / เมนูอาหาร / คลิปวิดีโอสั้น** ขึ้นจอทีวีในห้องคาราโอเกะทั้ง 12 ห้อง (V1–V4, A1–A8)
แก้ไขจากคอมกลางของร้าน (หรือมือถือ) แล้วจอทุกห้องเปลี่ยนตามภายใน ~1–2 นาที

**ใช้งานจริงที่: <https://rbtv.ajpatpon.com/>** (Host ของร้าน) — แผงควบคุม <https://rbtv.ajpatpon.com/admin.html>

ติดตั้งได้ 2 แบบ: **Host ของร้าน (PHP)** — แนะนำ หรือ **GitHub Pages** (ไม่ต้องมี server) — หน้า Admin เลือกให้เองอัตโนมัติ

```
 คอมกลาง (Chrome)                    GitHub (cloud)                      กล่อง Android ในห้อง
┌──────────────────┐   commit    ┌──────────────────────────┐   poll    ┌──────────────────────┐
│ admin.html       │ ──────────▶ │ repo: data/config.json   │ ◀──────── │ tv.html?room=V1      │
│ แก้เมนู/ราคา/สื่อ │  (API+Token)│       media/*.jpg,*.mp4  │  ทุก 30 วิ │ tv.html?room=A1 ...  │
└──────────────────┘             │ GitHub Pages (เว็บ)       │ ────────▶ │ วนเล่นสไลด์เต็มจอ       │
                                 └──────────────────────────┘           └──────────────────────┘
```

## หน้าเว็บ

| หน้า | ใช้ทำอะไร |
|---|---|
| [`index.html`](https://rbtv.ajpatpon.com/) | หน้าแรก — ลิงก์ไปแผงควบคุม และจอของแต่ละห้อง |
| [`admin.html`](https://rbtv.ajpatpon.com/admin.html) | **แผงควบคุม** — จัดการห้อง, เพลย์ลิสต์, เมนูอาหาร, คลังสื่อ, ตั้งค่า |
| [`tv.html?room=V1`](https://rbtv.ajpatpon.com/tv.html?room=V1) | **จอ TV** — เปิดบนจอของห้อง V1 (เปลี่ยนชื่อห้องตามจริง) |

## ความสามารถ

- **ห้อง / จอ** — แต่ละห้องเลือกโหมดได้: `คาราโอเกะ` (เปิดแอปร้องเพลง) · `อัตโนมัติ` (ห้องว่างนานๆ → โปรโมท, กดรีโมต → กลับร้องเพลง) · `เล่นสื่อ` (วนเพลย์ลิสต์) · `ข้อความ` (เต็มจอ เช่น “เหลือเวลา 15 นาที”) · `โลโก้` · `ปิดจอ`
  - ข้อความต้อนรับเฉพาะห้อง เช่น “สุขสันต์วันเกิดคุณเอ” เด้งขึ้นทุก 1 นาที
  - ปุ่มสั่งรีโหลดจอระยะไกล, ตั้งทุกห้องพร้อมกันได้ในคลิกเดียว
- **การจอง & จอหน้าร้าน** — กรอกการจองแบบ 2 รอบ (รอบเช้า 11:00–16:00, รอบค่ำ 17:00–23:30 — แก้เวลาได้) ระบุห้อง, ชื่อ, จำนวนคน, โอกาส → จอหน้าร้านขึ้นรายการจอง + สไลด์ และจอห้องที่จองขึ้น “ยินดีต้อนรับ + ชื่อ” อัตโนมัติ
  - จอพิเศษมีโหมด `จอง+สไลด์` · `รายการจอง` (เต็มจอ) · `เล่นสื่อ` · `ข้อความ` · `โลโก้` · `ปิดจอ` — ลิงก์ `tv.html?room=lobby`
  - **การวางจอ** (ตั้งรายจอ): `ตามเครื่อง` · `แนวตั้ง หมุน 90° ตามเข็ม` · `แนวตั้ง หมุน 90° ทวนเข็ม` — ใช้กับทีวีที่ยึดแนวตั้งแต่ตัวเครื่อง/Smart TV ส่งภาพแนวนอน ถ้าเครื่องหมุนจอเองได้ (เช่น Windows → Display orientation: Portrait) เลือก `ตามเครื่อง` แล้วหน้าจอจัดแนวตั้งให้เอง · รูปสำหรับจอแนวตั้ง 1080×1920
  - รายการจองเปิดดูได้จากหน้าเว็บ (`data/config.json` ที่จอดึงไป — ถ้าใช้ GitHub Pages ยังอยู่ใน repo สาธารณะด้วย): ใส่แค่ชื่อที่จะโชว์ **ห้ามใส่เบอร์โทร** · การจองเก่ากว่าเมื่อวานถูกลบตอนบันทึก (แต่ยังอยู่ในประวัติ commit) · มีตัวเลือกย่อนามสกุล
- **เพลย์ลิสต์** — สไลด์ 4 แบบ: รูปภาพ · วิดีโอ · หน้าเมนูอาหาร (สร้างอัตโนมัติจากข้อมูลเมนู) · สไลด์โปรโมชั่น (พิมพ์ข้อความ+ราคา ไม่ต้องทำภาพ)
- **เมนูอาหาร** — แก้ชื่อ/ราคา/ป้าย (แนะนำ, ขายดี, ใหม่, เผ็ด) ติ๊ก “ของหมด” แล้วหายจากจอทันที
- **คลังสื่อ** — ลากไฟล์มาวาง รูปถูกย่อเหลือ ≤1920px อัตโนมัติ
- **ตัวอย่างก่อนบันทึก** — ปุ่ม “ตัวอย่าง” เปิดจอจำลองด้วยข้อมูลที่ยังไม่บันทึก
- **ตัววิ่งด้านล่างจอ**, นาฬิกา, สีธีมร้าน, โลโก้
- จอ TV ทำงานต่อได้แม้เน็ตหลุด (จำข้อมูล+ไฟล์ล่าสุดไว้ในเครื่อง), กันจอดับ, รีเฟรชตัวเองทุก 12 ชม.
- ประวัติการแก้ไขทุกครั้งอยู่ใน GitHub commit — ย้อนกลับได้

## ติดตั้งบน Host ของร้าน (Plesk / PHP) — แนะนำ

ข้อดีเทียบกับ GitHub Pages: บันทึกแล้วขึ้นจอใน ~30 วินาที · ใช้รหัสผ่านแทน GitHub Token · รายชื่อลูกค้าที่จองไม่ไปอยู่ใน repo สาธารณะ · มี backup อัตโนมัติ
ต้องการแค่ PHP 7.2 ขึ้นไป (ไม่ต้องใช้ database)

### 1) อัปโหลดไฟล์
1. Plesk → **Websites & Domains** → เลือกโดเมน/ซับโดเมน (ของร้านคือ `rbtv.ajpatpon.com`) → **Files**
2. เข้าโฟลเดอร์เว็บของโดเมนนั้น (Document root) → **Upload** ไฟล์ `rabiangbua-tv-host.zip`
3. คลิกขวาที่ ZIP → **Extract Files** → ลบไฟล์ ZIP ทิ้ง
4. ตรวจว่า `index.html`, `admin.html`, `tv.html`, `api/`, `data/`, `media/` อยู่ในโฟลเดอร์เว็บโดยตรง (ไม่ซ้อนในโฟลเดอร์ย่อย)
5. (แนะนำ) **SSL/TLS Certificates** → เปิด Let's Encrypt ให้โดเมนนี้ เพื่อใช้ `https://`

### 2) ตั้งรหัสผ่านผู้ดูแล
เปิด `https://rbtv.ajpatpon.com/admin.html` → แถบด้านบนจะให้ **ตั้งรหัสผ่าน (ครั้งแรก)** → ตั้งรหัสอย่างน้อย 4 ตัว (ใส่ผิด 5 ครั้งจะถูกล็อก 15 นาที)
เครื่องอื่นเข้าด้วยรหัสเดียวกัน · เปลี่ยนรหัส/ออกจากระบบได้ที่แท็บ **ตั้งค่า**
ถ้าขึ้น *Host เขียนไฟล์ไม่ได้* → ใน Files ตั้ง permission ให้โฟลเดอร์ `data`, `media`, `api` เขียนได้

### 3) อัปเดตโปรแกรมครั้งต่อไป
อัปโหลดไฟล์ใหม่ทับได้ **ยกเว้น** อย่าทับ/ลบ:
- `data/config.json` (ข้อมูลร้านทั้งหมด) และ `data/backups/`
- `media/` (รูปและวิดีโอที่อัปโหลด)
- `api/secret.php` (รหัสผ่านผู้ดูแล — ลบไฟล์นี้ = ตั้งรหัสใหม่ได้ ใช้ตอนลืมรหัส)

**กู้ข้อมูลจาก backup**: เปิดไฟล์ใน `data/backups/` ลบบรรทัดแรก (`<?php … ?>`) แล้วบันทึกทับเป็น `data/config.json`

> ร้านติดตั้งบน Host แล้วที่ `https://rbtv.ajpatpon.com/` — ใช้ลิงก์นี้ในขั้นตอนตั้งค่าจอด้านล่าง (แทน `patpon.github.io/WebAppcontrolTV`)

## ติดตั้งแบบ GitHub Pages (ทางเลือก)

### 1) เปิด GitHub Pages
repo → **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
รอ 1–2 นาที เว็บจะอยู่ที่ `https://patpon.github.io/WebAppcontrolTV/`

### 2) สร้าง Token สำหรับแผงควบคุม
GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
- Repository access: **Only select repositories** → `WebAppcontrolTV`
- Permissions → Repository permissions → **Contents: Read and write**
- Expiration: ตามต้องการ (เช่น 1 ปี)

> ⚠️ Token = กุญแจแก้ไขข้อมูลร้าน ใส่เฉพาะบนคอมกลาง/เครื่องของผู้ดูแล ห้ามแชร์ ถ้าหลุดให้ Revoke ที่หน้าเดิมทันที

### 3) เชื่อมแผงควบคุม (บนคอมกลาง)
เปิด `https://patpon.github.io/WebAppcontrolTV/admin.html` → แท็บ **ตั้งค่า** → ใส่ Token → **เชื่อมต่อ**
แนะนำ bookmark ไว้บน Chrome ของคอมกลาง

## ตั้งค่าจอในแต่ละห้อง — ใช้ Firefox ที่มีในกล่องอยู่แล้ว (ไม่ติดตั้งอะไรเพิ่ม)
ทำครั้งเดียวต่อห้อง:
1. บนกล่อง เปิดแอป **Firefox** → พิมพ์ที่อยู่เว็บ `rbtv.ajpatpon.com` (ถ้าใช้ GitHub Pages: `patpon.github.io/WebAppcontrolTV`) → OK
2. ใช้ปุ่มลูกศรเลือกห้อง (V1–V4, A1–A8) → กด **OK** → จอโปรโมทเริ่มเล่น
3. กด **OK** อีกครั้งเพื่อเต็มจอ
4. กล่องจะจำห้องไว้ — ครั้งต่อไปเปิด Firefox จะกลับมาหน้าเดิม หรือถ้าเปิดหน้าแรก จะเข้าห้องตัวเองใน 15 วินาที

**(แนะนำ) ติดตั้งเป็นแอป — ไอคอน “ระเบียงบัว TV” บนหน้า Home ของกล่อง**
เว็บเป็น PWA แล้ว (`manifest.json` + `sw.js`) เปิดจากไอคอนจะเต็มจอทันที ไม่มีแถบที่อยู่เว็บ
1. ใน Firefox เปิด `rbtv.ajpatpon.com` แล้วเลือกห้องให้เรียบร้อยก่อน (ข้อ 1–2 ด้านบน)
2. กดปุ่ม **เมนู ⋮** ของ Firefox → **ติดตั้ง / Install** หรือ **เพิ่มไปยังหน้าจอหลัก / Add to Home screen** → ยืนยัน
3. กลับหน้า Home ของกล่อง → เปิดไอคอน **ระเบียงบัว TV** → เข้าห้องที่จำไว้ใน 15 วินาที → กด **OK** ครั้งเดียวเพื่อเปิดเสียง/กันจอดับ

ถ้าไม่มีเมนูติดตั้ง หรือติดตั้งแล้วไอคอนไม่โผล่ (launcher แบบ Android TV / Google TV ไม่แสดง shortcut จากเบราว์เซอร์) ให้ใช้ Firefox ตามปกติเหมือนเดิม

**ใช้งานทุกวัน**
- ห้องว่าง / ก่อนลูกค้าเข้า → เปิดไอคอน **ระเบียงบัว TV** (หรือ **Firefox** ถ้าไม่ได้ติดตั้งแอป) → กด OK ให้เต็มจอ
- ลูกค้าเข้าห้อง → กดปุ่ม **Home** บนรีโมต → เปิดแอปคาราโอเกะตามปกติ

ไม่แตะโปรแกรมคาราโอเกะ ไม่ต้องเปิด ADB — Firefox เป็นแอปที่มีในกล่องอยู่แล้ว
ถ้าจอดับ/ขึ้น screensaver ระหว่างโปรโมท ให้ใส่วิดีโอไว้ในเพลย์ลิสต์ หรือปิด Screen saver ในตั้งค่ากล่อง

**ทางเลือกอื่น**
- ทีวีเป็น Google TV / Android TV → ติดตั้ง Fully Kiosk บนทีวีเอง แล้วสลับด้วยปุ่ม Input
- ซื้อ TV stick เสียบ HDMI ช่องที่ว่าง → แยกจากระบบคาราโอเกะ 100%
- **bridge** (สลับแอปอัตโนมัติผ่าน ADB) ใน [bridge/README.md](bridge/README.md) — ปิดไว้เป็นค่าเริ่มต้น ใช้เฉพาะเมื่อเจ้าของระบบคาราโอเกะอนุญาต

## ใช้งานประจำวัน

1. เปิด `https://rbtv.ajpatpon.com/admin.html` บนคอมกลาง
2. แก้สิ่งที่ต้องการ (ราคาเมนู, โปรฯ, ข้อความห้อง)
3. กด **ตัวอย่าง** เพื่อดูหน้าจอจำลอง (ถ้าต้องการ)
4. กด **บันทึก & ส่งขึ้นจอ** (หรือ `Ctrl+S`) → จอทุกห้องเปลี่ยนภายใน ~30 วินาที (Host ร้าน) หรือ ~1–2 นาที (GitHub Pages)

รีโมตบนหน้าโปรโมท: `→` สไลด์ถัดไป · `←` ย้อนกลับ · `OK` เต็มจอ · `↑` แล้ว `OK` กลับหน้าเลือกห้อง (หรือ `Back`)  
บน PC / มือถือ: ขยับเมาส์หรือแตะจอ → ปุ่ม **หน้าแรก** โผล่ด้านบนกลางจอ 4 วินาที

## ข้อจำกัด / คำแนะนำ

- **วิดีโอ**: MP4 (H.264) 720p–1080p ความยาว 15–60 วินาที ขนาด ≤ 50 MB (สูงสุด ~95 MB) — ย่อด้วย CapCut / HandBrake ก่อนอัปโหลด
- วิดีโอเล่น **ปิดเสียง** เป็นค่าเริ่มต้น เพื่อไม่กวนการร้องเพลง (เปิดเสียงรายคลิปได้)
- อัปเดตขึ้นจอใช้เวลา ~1–2 นาที (GitHub Pages build) ไม่ใช่ทันที
- repo แบบ Public → ไฟล์สื่อ/เมนูดูได้จากภายนอก (ปกติเป็นข้อมูลโปรโมทอยู่แล้ว) — ห้ามใส่ข้อมูลลับใน repo
- พื้นที่ GitHub Pages แนะนำรวมไม่เกิน 1 GB — ลบวิดีโอเก่าที่ไม่ใช้ในแท็บ คลังสื่อ

## โครงสร้างไฟล์

```
index.html            หน้าแรก
admin.html            แผงควบคุม
tv.html               จอ TV
sw.js                 service worker (cache สื่อบนกล่อง Android)
manifest.json         PWA — ชื่อแอป/ไอคอน สำหรับติดตั้งลงหน้า Home ของกล่อง
assets/img/icons/     ไอคอนแอป (สร้างจากโลโก้ร้าน)
data/config.json      ข้อมูลทั้งหมด (ห้อง, เพลย์ลิสต์, เมนู, รายการสื่อ)
media/                ไฟล์รูป/วิดีโอ
assets/js/common.js   โค้ดร่วม
assets/js/github.js   เชื่อม GitHub API (commit ทีเดียวทั้ง config + สื่อ)
assets/js/server.js   เชื่อม api/ บน Host ของร้าน (อัปโหลดแบบแบ่งก้อน)
api/index.php         API บน Host: รหัสผ่าน, บันทึก config, อัปโหลดสื่อ, backup
assets/js/admin.js    แผงควบคุม
assets/js/tv.js       ตัวเล่นบนจอ
bridge/               ตัวสลับแอปบนกล่อง Android ผ่าน ADB (รันบนคอมกลาง)
```

ทดสอบบนเครื่อง: `python -m http.server 8790` แล้วเปิด `http://localhost:8790/`
