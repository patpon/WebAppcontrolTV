# ระเบียงบัว — ระบบควบคุมจอโปรโมทในห้องคาราโอเกะ

WebApp สำหรับส่ง **รูปโปรโมชั่น / เมนูอาหาร / คลิปวิดีโอสั้น** ขึ้นจอทีวีในห้องคาราโอเกะทั้ง 12 ห้อง (V1–V4, A1–A8)
แก้ไขจากคอมกลางของร้าน (หรือมือถือ) แล้วจอทุกห้องเปลี่ยนตามภายใน ~1–2 นาที

ทำงานบน **GitHub ล้วน** — ไม่ต้องมี server ไม่มีค่าเช่า

```
 คอมกลาง (Chrome)                    GitHub (cloud)                      กล่อง Android ในห้อง
┌──────────────────┐   commit    ┌──────────────────────────┐   poll    ┌──────────────────────┐
│ admin.html       │ ──────────▶ │ repo: data/config.json   │ ◀──────── │ tv.html?room=V1      │
│ แก้เมนู/ราคา/สื่อ │  (API+Token)│       media/*.jpg,*.mp4  │  ทุก 30 วิ │ tv.html?room=A1 ...  │
└──────────────────┘             │ GitHub Pages (เว็บ)       │ ────────▶ │ วนเล่นสไลด์เต็มจอ       │
                                 └──────────────────────────┘           └──────────────────────┘
```

## หน้าเว็บ

| หน้า | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าแรก — ลิงก์ไปแผงควบคุม และจอของแต่ละห้อง |
| `admin.html` | **แผงควบคุม** — จัดการห้อง, เพลย์ลิสต์, เมนูอาหาร, คลังสื่อ, ตั้งค่า |
| `tv.html?room=V1` | **จอ TV** — เปิดบนจอของห้อง V1 (เปลี่ยนชื่อห้องตามจริง) |

## ความสามารถ

- **ห้อง / จอ** — แต่ละห้องเลือกโหมดได้: `คาราโอเกะ` (เปิดแอปร้องเพลง) · `อัตโนมัติ` (ห้องว่างนานๆ → โปรโมท, กดรีโมต → กลับร้องเพลง) · `เล่นสื่อ` (วนเพลย์ลิสต์) · `ข้อความ` (เต็มจอ เช่น “เหลือเวลา 15 นาที”) · `โลโก้` · `ปิดจอ`
  - ข้อความต้อนรับเฉพาะห้อง เช่น “สุขสันต์วันเกิดคุณเอ” เด้งขึ้นทุก 1 นาที
  - ปุ่มสั่งรีโหลดจอระยะไกล, ตั้งทุกห้องพร้อมกันได้ในคลิกเดียว
- **การจอง & จอทางเข้า** — กรอกการจองวันนี้ (เวลา, ชื่อ, ห้อง, จำนวนคน, โอกาส) → จอทางเข้าขึ้นรายการจอง + สไลด์ และจอห้องที่จองขึ้น “ยินดีต้อนรับ + ชื่อ” อัตโนมัติ
  - จอพิเศษมีโหมด `จอง+สไลด์` · `รายการจอง` (เต็มจอ) · `เล่นสื่อ` · `ข้อความ` · `โลโก้` · `ปิดจอ` — ลิงก์ `tv.html?room=lobby`
  - ข้อมูลอยู่ใน repo สาธารณะ: ใส่แค่ชื่อที่จะโชว์ **ห้ามใส่เบอร์โทร** · การจองเก่ากว่าเมื่อวานถูกลบตอนบันทึก (แต่ยังอยู่ในประวัติ commit) · มีตัวเลือกย่อนามสกุล
- **เพลย์ลิสต์** — สไลด์ 4 แบบ: รูปภาพ · วิดีโอ · หน้าเมนูอาหาร (สร้างอัตโนมัติจากข้อมูลเมนู) · สไลด์โปรโมชั่น (พิมพ์ข้อความ+ราคา ไม่ต้องทำภาพ)
- **เมนูอาหาร** — แก้ชื่อ/ราคา/ป้าย (แนะนำ, ขายดี, ใหม่, เผ็ด) ติ๊ก “ของหมด” แล้วหายจากจอทันที
- **คลังสื่อ** — ลากไฟล์มาวาง รูปถูกย่อเหลือ ≤1920px อัตโนมัติ
- **ตัวอย่างก่อนบันทึก** — ปุ่ม “ตัวอย่าง” เปิดจอจำลองด้วยข้อมูลที่ยังไม่บันทึก
- **ตัววิ่งด้านล่างจอ**, นาฬิกา, สีธีมร้าน, โลโก้
- จอ TV ทำงานต่อได้แม้เน็ตหลุด (จำข้อมูล+ไฟล์ล่าสุดไว้ในเครื่อง), กันจอดับ, รีเฟรชตัวเองทุก 12 ชม.
- ประวัติการแก้ไขทุกครั้งอยู่ใน GitHub commit — ย้อนกลับได้

## ติดตั้งครั้งแรก

### 1) เปิด GitHub Pages
repo → **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
รอ 1–2 นาที เว็บจะอยู่ที่ `https://patpon.github.io/WebAppcontrolTV/`

### 2) สร้าง Token สำหรับแผงควบคุม
GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
- Repository access: **Only select repositories** → `WebAppcontrolTV`
- Permissions → Repository permissions → **Contents: Read and write**
- Expiration: ตามต้องการ (เช่น 1 ปี)

> ⚠️ Token = กุญแจแก้ไขข้อมูลร้าน ใส่เฉพาะบนคอมกลาง/เครื่องของผู้ดูแล ห้ามแชร์ ถ้าหลุดให้ Revoke ที่หน้าเดิมทันที

### 3) เชื่อมแผงควบคุม (บนคอมกลาง)
เปิด `https://patpon.github.io/WebAppcontrolTV/admin.html` → แท็บ **ตั้งค่า** → ใส่ Token → **เชื่อมต่อ**
แนะนำ bookmark ไว้บน Chrome ของคอมกลาง

### 4) ตั้งค่าจอในแต่ละห้อง — ใช้ Firefox ที่มีในกล่องอยู่แล้ว (ไม่ติดตั้งอะไรเพิ่ม)
ทำครั้งเดียวต่อห้อง:
1. บนกล่อง เปิดแอป **Firefox** → พิมพ์ `patpon.github.io/WebAppcontrolTV` → OK
2. ใช้ปุ่มลูกศรเลือกห้อง (V1–V4, A1–A8) → กด **OK** → จอโปรโมทเริ่มเล่น
3. กด **OK** อีกครั้งเพื่อเต็มจอ
4. กล่องจะจำห้องไว้ — ครั้งต่อไปเปิด Firefox จะกลับมาหน้าเดิม หรือถ้าเปิดหน้าแรก จะเข้าห้องตัวเองใน 3 วินาที

**ใช้งานทุกวัน**
- ห้องว่าง / ก่อนลูกค้าเข้า → เปิด **Firefox** (หน้าโปรโมทเล่นต่อจากเดิม) → กด OK ให้เต็มจอ
- ลูกค้าเข้าห้อง → กดปุ่ม **Home** บนรีโมต → เปิดแอปคาราโอเกะตามปกติ

ไม่แตะโปรแกรมคาราโอเกะ ไม่ต้องเปิด ADB — Firefox เป็นแอปที่มีในกล่องอยู่แล้ว
ถ้าจอดับ/ขึ้น screensaver ระหว่างโปรโมท ให้ใส่วิดีโอไว้ในเพลย์ลิสต์ หรือปิด Screen saver ในตั้งค่ากล่อง

**ทางเลือกอื่น**
- ทีวีเป็น Google TV / Android TV → ติดตั้ง Fully Kiosk บนทีวีเอง แล้วสลับด้วยปุ่ม Input
- ซื้อ TV stick เสียบ HDMI ช่องที่ว่าง → แยกจากระบบคาราโอเกะ 100%
- **bridge** (สลับแอปอัตโนมัติผ่าน ADB) ใน [bridge/README.md](bridge/README.md) — ปิดไว้เป็นค่าเริ่มต้น ใช้เฉพาะเมื่อเจ้าของระบบคาราโอเกะอนุญาต

## ใช้งานประจำวัน

1. เปิด `admin.html` บนคอมกลาง
2. แก้สิ่งที่ต้องการ (ราคาเมนู, โปรฯ, ข้อความห้อง)
3. กด **ตัวอย่าง** เพื่อดูหน้าจอจำลอง (ถ้าต้องการ)
4. กด **บันทึก & ส่งขึ้นจอ** (หรือ `Ctrl+S`) → จอทุกห้องเปลี่ยนภายใน ~1–2 นาที

รีโมตบนหน้าโปรโมท: `→` สไลด์ถัดไป · `←` ย้อนกลับ · `OK` เต็มจอ · `Back` กลับหน้าเลือกห้อง

## ข้อจำกัด / คำแนะนำ

- **วิดีโอ**: MP4 (H.264) 720p–1080p ความยาว 15–60 วินาที ขนาด ≤ 50 MB (สูงสุด ~95 MB) — ย่อด้วย CapCut / HandBrake ก่อนอัปโหลด
- วิดีโอเล่น **ปิดเสียง** เป็นค่าเริ่มต้น เพื่อไม่กวนการร้องเพลง (เปิดเสียงรายคลิปได้)
- อัปเดตขึ้นจอใช้เวลา ~1–2 นาที (GitHub Pages build) ไม่ใช่ทันที
- repo แบบ Public → ไฟล์สื่อ/เมนูดูได้จากภายนอก (ปกติเป็นข้อมูลโปรโมทอยู่แล้ว) — ห้ามใส่ข้อมูลลับใน repo
- พื้นที่ GitHub Pages แนะนำรวมไม่เกิน 1 GB — ลบวิดีโอเก่าที่ไม่ใช้ในแท็บ คลังสื่อ

## โครงสร้างไฟล์

```
index.html            หน้าแรก
admin.html            แผงควบคุม
tv.html               จอ TV
sw.js                 service worker (cache สื่อบนกล่อง Android)
data/config.json      ข้อมูลทั้งหมด (ห้อง, เพลย์ลิสต์, เมนู, รายการสื่อ)
media/                ไฟล์รูป/วิดีโอ
assets/js/common.js   โค้ดร่วม
assets/js/github.js   เชื่อม GitHub API (commit ทีเดียวทั้ง config + สื่อ)
assets/js/admin.js    แผงควบคุม
assets/js/tv.js       ตัวเล่นบนจอ
bridge/               ตัวสลับแอปบนกล่อง Android ผ่าน ADB (รันบนคอมกลาง)
```

ทดสอบบนเครื่อง: `python -m http.server 8790` แล้วเปิด `http://localhost:8790/`
